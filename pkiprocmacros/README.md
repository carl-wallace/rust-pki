# pkiprocmacros

![Apache2/MIT licensed][license-image]
![Rust Version][rustc-image]

Procedural macros that generate the typed accessors for path-processing settings and results in
[certval], the X.509 certification path validation library. The macros serve certval's own
definitions and are not intended for use elsewhere.
